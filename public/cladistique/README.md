# Banc cladistique

Recherche d'arbres les plus parcimonieux, consensus et bootstrap sur une matrice de caractères, dans le navigateur.

Première publication : 19 octobre 2026, sur paleophone.fr · version du 2 octobre 2026.

Ouvrir `index.html` dans un navigateur. Aucune ressource en ligne.

- matrices au format NEXUS ; trois matrices synthétiques intégrées pour essayer
- recherche heuristique (additions aléatoires, TBR), longueur des arbres
- consensus strict et majoritaire, bootstrap
- comparaison de versions de matrice
