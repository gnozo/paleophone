# Archéophone

Instrument à dessiner : un geste sur une cible devient une boucle ; les strates se superposent ; chaque son est un taxon dont on suit la lignée.

Première publication : 6 novembre 2026, sur paleophone.fr (version 3.0).

Ouvrir `index.html` dans un navigateur. Aucune ressource en ligne. Sur téléphone, vue simple par défaut (bouton « Plus » pour le reste).

- le rayon donne la hauteur, le temps du geste donne le rythme ; gammes, placement euclidien
- strates à vitesses relatives, cellules, rythmes (tāla), irruptions
- matières sonores par graine ; lignées : confirmer, varier, remonter, nouveau taxon, croiser ; bestiaire exportable
- MIDI entrée (apprentissage des curseurs, note = cellule suivante) et sortie (pitch bend microtonal)
- projets JSON, export audio, sauvegarde locale

## Historique

Archéophone (de ἀρχαῖος, ancien, et φωνή, la voix) est né sous le nom d'ORBE, un synthétiseur gestuel à strates. La version 3.0 ajoute les lignées de sons, l'entrée MIDI, la vue téléphone et l'horloge stable.
