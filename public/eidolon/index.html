Eidolon

Une visionneuse pour lire une surface avec la lumière. Une gravure, un relief, une trace n'apparaissent qu'à certains angles d'éclairage. Déplacer la lumière est un acte de lecture : chaque position révèle ou dissimule. Il n'y a pas de bonne vue, seulement des lectures différentes.

Modèles

Glisser des fichiers .glb ou .gltf (compression Draco acceptée), ou ouvrir une liste : ?liste=chemin/liste.json dans l'adresse, ou le bouton « exemples » qui lit exemples/exemples.json. Une liste est un fichier JSON : {"modeles":[{"url":"…","titre":"…","description":"…"}]}.

Caméra et lumière

Caméra : glisser pour tourner autour du modèle, molette ou pincement pour zoomer, clic droit pour décaler. La lumière suit la caméra. Lumière : glisser déplace la source dans le plan, molette (ou deux doigts) la rapproche ou l'éloigne, clic droit la monte ou la descend. Les positions sont exprimées en rayons du modèle : un réglage vaut d'un modèle à l'autre.

Vacillement : variation irrégulière de l'intensité et de la position, comme une flamme. Boucle : orbite complète, pendule (aller-retour, pour une paroi qu'on ne regarde que de face), ou aucune.

Enchaîner des modèles

→ et ← passent strictement au modèle suivant ou précédent. Si celui-ci charge encore, le modèle affiché reste manipulable et une pastille apparaît tant que la touche est tenue ; le passage se fait dès que le modèle est prêt. Maj + flèche saute au prochain modèle déjà chargé. Les modèles voisins se chargent à l'avance ; les plus éloignés sont libérés pour économiser la mémoire.

Session

« Session .paleo » écrit la liste des modèles (références, pas les fichiers), le modèle courant, la caméra et la lumière dans un fichier .paleo, le format commun des outils Paléophone. Le rouvrir restaure l'état ; les modèles glissés depuis le disque doivent être glissés à nouveau.

Mise en route

Eidolon se charge par HTTP : en ligne, ou en local avec python -m http.server dans le dossier, puis http://localhost:8000/eidolon/eidolon.html. Né d'une visionneuse de relevés de grotte ornée (2026), généralisé pour la suite Paléophone.
