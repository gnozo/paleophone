# Diaclase

Enregistrement et analyse du rythme des commandes de jeu vidéo : manette.

Première publication : 23 mars 2026, sur GitHub (version 0.1) · version 1.10.0, 19 octobre 2026.

Ouvrir `diaclase.html` dans un navigateur. Hors de la fenêtre du navigateur, seule la manette est captée.

- capture horodatée à la milliseconde
- appuis par seconde, régularité, complexité, durée d'appui, dominance des mains, sticks
- régimes de jeu, d'après la rythmanalyse de M. Triclot
- marqueurs, relecture, export des sessions en JSON
- Chart.js inclus, aucune ressource en ligne

## Historique

Diaclase est un outil de captation des signaux de contrôle pour manettes de jeu vidéo connectées à un ordinateur personnel. Il est pensé pour la constitution de bases de données en vue de l'analyse micro-ethnographique des parties enregistrées.
